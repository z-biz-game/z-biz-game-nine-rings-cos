九连环怎么玩

  1. 剑上有九个环，目标是把它们全部拨离剑。
  2. 第 1 环（最右首环）随时能拨，上、下都行。
  3. 要拨第 k 环（k ≥ 2）：第 k−1 环必须在剑上，而且它下面（更靠左）的环必须全部离剑。一次只能动一环。
  4. 所以拆到第 5 环之前，常要把已经拆下的环再装回去 —— 这不是失误，是这条路。
  5. 面板上的「最少」不是设计值：九个环只有 2⁹ = 512 种状态，程序把整张图穷尽走完（BFS）量出来的，并与闭式公式 (2^(n+1) − (n 奇 ? 1 : 2)) / 3 对过账。全上到全下 = 341 步。

玩法：什么时候能拨哪个环

目标：把九个环全部从剑上拨下来。全部离剑时状态是 SOLVED = 0（js/core/game.js:12）。

动作只有一个：拨一个环上剑或离剑。一个位置就是 n 个比特——第 k 位是第 k+1 个环，1 表示在剑上。整个游戏只有一条规则决定"这次点击算不算数"，就是 canToggle()：

  • 第 1 个环永远可以拨。
  • 要拨第 k 个环（k ≥ 2），必须同时满足两件事：
    ① 第 k−1 个环在剑上；
    ② 第 1 到第 k−2 个环全部离剑（state & ((1 << (k-1)) - 1) === 0）。

也就是说：要动一个环，得先把它前面那个环挂上去，而更前面的环必须全清空。不满足时点了不算数，局面原样不动（js/main.js:210 那句 if (!moved) { view.redraw(); return false; }）。

怎么操作：点剑上的环。手指点画布、测试链接的复现、演示走的路线，最终都汇到 commit(k) 这一处（js/main.js:209），受同一条规则管——所以你看到的演示和提示不会走出一条你走不出的棋。

为什么它难：这条规则让 512 个状态连成一条路径而不是一团乱麻（DESIGN.md 1.2），于是"最少几步"不是估值也不是启发式，是查一次数组。

这一关的数字从哪来

九个环在剑上只有 2^9 = 512 种状态，所以 js/core/solve.js 把整张状态图穷尽走完（一次 BFS，512 个结点），每个状态的最少拨环次数都是查表得来的事实。这个数还与 classical 闭式公式 (2^(n+1) − (n 奇 ? 1 : 2)) / 3 在 n = 1..12 上逐一对账（node test/solve.test.mjs），搜索器不是自己给自己打分。

难度带也不是拍脑袋：512 个状态的距离直方图算分位数切四刀，由 tools/bake.mjs 打印并写进 js/data/levels.js。
